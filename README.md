# CoinTrader: 업비트 자동매매 웹 대시보드

업비트 Open API를 사용하는 코인 자동매매 프로그램입니다. 차트, 조건검색, 뉴스·공시 수집, 전략 자동매매, 백테스트를 하나의 웹 대시보드에서 제공합니다.

> ⚠️ 투자 손실 책임은 사용자에게 있습니다. 반드시 **모의투자와 백테스트로 충분히 검증한 뒤** 소액으로 실거래를 시작하세요.

## 주요 기능

| 화면 | 기능 |
|---|---|
| 트레이딩 | 원화마켓 종목 목록(검색·관심·보유), 실시간 캔들 차트(1분~주봉, 이평/볼린저/거래량, RSI/MACD), 실시간 호가, 지정가/시장가 주문, 보유자산·주문내역·종목별 뉴스·엔진 로그 |
| 조건검색 | 거래대금·등락률·RSI 조건, 유의종목 제외, 프리셋(과매도/급등/급락) |
| 자동매매 | 전략 생성/편집/시작/정지/청산, 전략별 보유수량·평가손익·실현손익, 전략 로그 |
| 백테스트 | 같은 전략 코드로 과거 캔들 재생, 수익률/MDD/샤프/승률/손익비, 매매 시점·자산 곡선 차트, 결과로 바로 전략 생성 |
| 뉴스·공시 | 업비트 공지(1분 주기), Google News, CryptoPanic(토큰 필요), DAXA·쟁글 공시, 코인/분류/출처/키워드 필터 |
| 설정 | 모의↔실거래 전환, 긴급정지/재개, 리스크 한도, API 키 등록(암호화 저장), 자산 추이, 모의계좌 초기화 |

**기본 탑재 전략**: 변동성 돌파, 이동평균 교차, RSI/볼린저 역추세, 그리드, 분할매수(DCA)

**안전장치**
- 기본값은 모의투자입니다. 실거래를 하려면 `.env`의 `TRADING_MODE=live` 설정과 대시보드에서 비밀번호 재확인이 모두 필요합니다.
- 1회 최대 주문금액, 종목당 최대 비중, 일일 손실 한도(도달 시 자동 정지), 긴급정지(미체결 취소와 선택적 전량 청산)를 제공합니다.
- 업비트 공지에서 유의종목 지정이나 거래지원 종료가 감지되면 해당 코인 매수를 자동으로 차단합니다.

## 설치

Python 3.11 이상이 필요합니다.

```bash
# Debian/Ubuntu 에서 venv 모듈이 없다면 먼저: sudo apt install python3-venv  (Python 3.14 는 python3.14-venv)
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
cp .env.example .env        # ADMIN_PASSWORD 는 반드시 변경
```

## 실행

```bash
.venv/bin/python -m app                         # .env 의 HOST/PORT (기본 127.0.0.1:8000)
# 또는 개발 중 자동 리로드
.venv/bin/uvicorn app.main:app --reload
```

브라우저에서 http://127.0.0.1:8000 에 접속해 `ADMIN_PASSWORD`로 로그인합니다.

서버는 기본적으로 `127.0.0.1`에만 바인딩됩니다. 외부에서 접속하려면 HTTPS 리버스 프록시(nginx, Caddy 등) 뒤에 두세요. 실거래 서버를 공개 인터넷에 직접 노출하지 마세요.

## Windows 설치파일 (배포용)

### 사용자: 설치와 실행
1. `CoinTrader-Setup-x.y.z.exe`를 실행해 설치합니다. 관리자 권한 없이 사용자 폴더에도 설치할 수 있습니다.
2. 시작 메뉴나 바탕화면의 **CoinTrader**를 실행합니다.
3. 처음 실행하면 입력 창에서 대시보드 비밀번호(8자 이상)를 정합니다. 설정이 끝나면 브라우저가 자동으로 열립니다.
4. 프로그램은 창 없이 **작업표시줄 오른쪽 알림 영역(트레이)**에서 실행됩니다. 브라우저를 닫아도 자동매매는 계속됩니다.
   - 아이콘을 더블클릭하면 대시보드가 열립니다.
   - 오른쪽 클릭 메뉴: 현재 상태(모드·자산), 긴급정지, Windows 시작 시 자동 실행, 데이터 폴더 열기, 로그 파일 열기, 종료
   - 체결, 오류, 유의종목 공지는 Windows 알림으로 표시됩니다.
   - 트레이 아이콘이 보이지 않으면 알림 영역의 ^ 버튼을 눌러 숨겨진 아이콘을 확인하세요.
5. 이미 실행 중일 때 다시 실행하면 새로 띄우지 않고 대시보드만 엽니다.
6. 완전히 끄려면 트레이 메뉴에서 **종료**를 누릅니다. 실행 중인 전략이 있으면 먼저 확인을 묻습니다.

PC가 절전 모드에 들어가면 자동매매도 멈춥니다. 상시 운용하려면 Windows 전원 설정에서 절전 모드를 끄세요.

설정, 거래 기록, 암호화된 API 키는 `%LOCALAPPDATA%\CoinTrader`에 저장되므로 업데이트를 위해 재설치해도 그대로 유지됩니다. 설정을 바꾸려면 이 폴더의 `.env`를 수정한 뒤 다시 실행하세요. 제거할 때 데이터 폴더도 지울지 묻습니다.

> Windows SmartScreen이 "알 수 없는 게시자" 경고를 띄울 수 있습니다. 코드 서명 인증서로 서명하지 않은 실행파일이기 때문입니다. 배포 규모가 크다면 코드 서명을 권장합니다.

### 개발자: 설치파일 빌드
**방법 1: Windows PC에서 빌드**
1. [Python 3.12](https://www.python.org/downloads/windows/)를 설치합니다. 설치할 때 "Add python.exe to PATH"를 체크하세요.
2. 설치 마법사까지 만들려면 [Inno Setup 6](https://jrsoftware.org/isdl.php)도 설치합니다.
3. 프로젝트 폴더에서 `packaging\build_windows.bat`를 실행합니다. 테스트 → 실행파일 생성 → 설치 마법사 생성이 순서대로 진행됩니다.
4. 결과물
   - 실행파일 폴더: `dist\CoinTrader\CoinTrader.exe`
   - 설치 마법사: `dist\installer\CoinTrader-Setup-0.1.0.exe`

**방법 2: GitHub Actions (Windows PC 불필요)**
저장소를 GitHub에 올리고 Actions 탭에서 **Build Windows installer**를 수동 실행합니다. 이 워크플로는 테스트, 실행파일 생성, 실행파일 스모크 테스트, 설치 마법사 생성을 거칩니다. 완료되면 Artifacts에서 설치파일을 내려받을 수 있습니다. `v0.2.0`처럼 `v`로 시작하는 태그를 push하면 그 버전으로 빌드되어 Release에도 첨부됩니다.

## 업비트 API 키

업비트 › 마이페이지 › Open API 관리에서 발급합니다.
- 권한: **자산조회, 주문조회, 주문하기**만 체크합니다. **출금하기는 절대 체크하지 마세요.**
- 허용 IP: 이 프로그램이 실행되는 서버의 공인 IP만 등록합니다.
- 키는 `.env`에 넣거나 설정 화면에서 등록합니다. 설정 화면에서 등록한 키는 DB에 암호화되어 저장됩니다.

## 참고 및 한계

- 업비트 공지 수집은 업비트 웹이 사용하는 비공식 엔드포인트를 씁니다. 업비트가 이 엔드포인트를 바꾸면 수집이 실패할 수 있으며, 실패 여부는 뉴스 화면의 수집기 상태에 표시됩니다.
- Google News RSS는 피드 약관상 개인적·비상업적 용도로만 사용할 수 있습니다.
- DAXA와 쟁글은 공개 API가 없습니다. 그래서 뉴스 검색으로 수집하고, `DISCLOSURE_SCRAPE_URLS`를 지정한 경우에만 해당 페이지를 직접 스크래핑합니다.
- 백테스트는 봉 내부 가격 경로를 가정하고, 슬리피지와 수수료를 단순 모델로 반영합니다. 실제 체결 결과와 다를 수 있습니다.
- 모의투자의 지정가 미체결 주문은 메모리에만 있으므로, 서버를 재시작하면 취소됩니다.
